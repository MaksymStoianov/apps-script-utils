Functions for working with file paths and URLs.

| Function                                                                                                                         | Return type                                                                                                    | Brief description                                                                                |

| [`isAbsolute`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/isAbsolute.ts)                         | `Boolean`                                                                                                      | Determines if a given path is an absolute path.                                                  |
| [`isRelative`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/isRelative.ts)                         | `Boolean`                                                                                                      | Determines if a given path is a relative path.                                                   |
| [`isValidDomain`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/isValidDomain.ts)                   | `Boolean`                                                                                                      | Validates if a string is a properly formatted domain name.                                       |
| [`join`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/join.ts)                                     | `String`                                                                                                       | Joins all given path segments together using the platform-specific separator.                    |
| [`nonAbsolute`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/nonAbsolute.ts) **New**               | `Boolean`                                                                                                      | Validates if a path is **not** absolute.                                                         |
| [`nonRelative`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/nonRelative.ts) **New**               | `Boolean`                                                                                                      | Validates if a path is **not** relative.                                                         |
| [`nonValidDomain`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/nonValidDomain.ts) **New**         | `Boolean`                                                                                                      | Validates if a value is **not** a valid domain name.                                             |
| [`normalize`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/normalize.ts)                           | `String`                                                                                                       | Normalizes a path by resolving `.` and `..` segments.                                            |

| [`requireAbsolute`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/requireAbsolute.ts) **New**       | `String`                                                                                                       | Ensures a path is absolute, throwing otherwise.                                                  |
| [`requireRelative`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/requireRelative.ts) **New**       | `String`                                                                                                       | Ensures a path is relative, throwing otherwise.                                                  |
| [`requireValidDomain`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/requireValidDomain.ts) **New** | `String`                                                                                                       | Ensures a value is a valid domain name, throwing otherwise.                                      |
