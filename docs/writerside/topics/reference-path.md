# path module

Functions for working with file paths and URLs.

| Function                                                                                                       | Return type                                                                                                    | Brief description                                                                                |
| :------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------- |
| [`isAbsolute`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/isAbsolute.ts)       | `Boolean`                                                                                                      | Determines if a given path is an absolute path.                                                  |
| [`isRelative`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/isRelative.ts)       | `Boolean`                                                                                                      | Determines if a given path is a relative path.                                                   |
| [`isValidDomain`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/isValidDomain.ts) | `Boolean`                                                                                                      | Validates if a string is a properly formatted domain name.                                       |
| [`join`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/join.ts)                   | `String`                                                                                                       | Joins all given path segments together using the platform-specific separator.                    |
| [`normalize`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/normalize.ts)         | `String`                                                                                                       | Normalizes a path by resolving `.` and `..` segments.                                            |
| [`parse`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/parse.ts)                 | [`ParsedPath`](https://github.com/MaksymStoianov/apps-script-utils/blob/main/src/net/path/types/ParsedPath.ts) | Breaks down a path into an object containing its constituent parts (root, dir, base, ext, name). |
