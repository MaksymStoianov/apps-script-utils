# Google Apps Script module

<link-summary>Every Google Apps Script function in the library, grouped by service.</link-summary>

<web-summary>Reference of every Google Apps Script function in apps-script-utils: spreadsheet, A1 notation, UI, Drive, Slides and Admin SDK helpers, with return types.</web-summary>

Functions scoped to specific Google Apps Script services: Sheets, Slides, Admin SDK, Drive, Docs, Forms, network
requests, and the built-in UI classes.

A **New** marker indicates a function added in the latest release; a **Deprecated** marker indicates a function
scheduled for removal in a future release.
