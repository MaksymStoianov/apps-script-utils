# Utilitaires de base

<link-summary>Toutes les fonctions indépendantes de l'environnement : gardes, tableaux, nombres, chaînes, objets, JSON et HTML.</link-summary>

<web-summary>Référence de toutes les fonctions indépendantes de l'environnement d'apps-script-utils : gardes isX/nonX/requireX, aides pour tableaux, nombres, chaînes, objets, JSON, HTML et temps.</web-summary>

Des fonctions qui ne dépendent d'aucun framework : vérification des types et des valeurs (`isX`/`nonX`/`requireX`),
manipulation de chaînes, de tableaux et d'objets, JSON et HTML. L'environnement Google Apps Script ne leur est pas
nécessaire.

La mention **New** signale une fonction ajoutée dans la dernière version ; **Deprecated** une fonction dont le
retrait est prévu dans une version future.
