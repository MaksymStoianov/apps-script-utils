# Исключения

<link-summary>Все классы исключений, которые бросает библиотека.</link-summary>

<web-summary>Справочник классов исключений apps-script-utils: что означает каждый и какие функции его бросают.</web-summary>

Типизированные классы исключений, используемые по всей библиотеке. Исключения, привязанные к сервисам (Таблицы,
Презентации, Admin SDK, сеть), наследуют общий базовый класс `Exception` — ради единообразной обработки ошибок.

Пометка **New** означает класс, добавленный в последнем выпуске; пометка **Deprecated** — класс, который планируется
удалить в одном из будущих выпусков.
