# Базовые утилиты

<link-summary>Все функции, не зависящие от среды выполнения: проверки, массивы, числа, строки, объекты, JSON и HTML.</link-summary>

<web-summary>Справочник всех независимых от среды функций apps-script-utils: проверки isX/nonX/requireX, работа с массивами, числами, строками, объектами, JSON, HTML и временем.</web-summary>

Функции, не привязанные к какому-либо фреймворку: проверка типов и значений (`isX`/`nonX`/`requireX`), работа со
строками, массивами и объектами, JSON и HTML. Среда выполнения Google Apps Script им не нужна.

Пометка **New** означает функцию, добавленную в последнем выпуске; пометка **Deprecated** — функцию, которую
планируется удалить в одном из будущих выпусков.
