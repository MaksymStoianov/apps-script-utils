# Экосистема

<link-summary>Фреймворк boot.gs, который построен на этой библиотеке, и Agent Skills, которые учат ИИ-агентов ею пользоваться.</link-summary>

<web-summary>Как apps-script-utils связан с фреймворком boot.gs для Google Apps Script и с Agent Skills, которые учат Claude Code, Gemini CLI и Cursor работать с обоими.</web-summary>

Библиотека полезна и сама по себе: установили, импортировали функцию — готово. При этом она часть небольшой
экосистемы для разработки на Google Apps Script, и двух соседей стоит знать.

## Boot.gs — фреймворк приложения

[Boot.gs](https://github.com/bootgs/boot) — фреймворк для структурированных приложений на Apps Script. Он приносит
контроллеры, декораторы, внедрение зависимостей и слой маршрутизации поверх `doGet` и `doPost` в среду, которая сама
по себе предлагает глобальные функции и ничего больше.

```bash
npm install bootgs
```

```typescript
import { Get, RestController } from "bootgs";

@RestController("api/sheet")
export class SheetController {
  @Get("active-range")
  getActiveRange(): string {
    return "This action returns the active sheet range.";
  }
}
```

**Отношение к этой библиотеке — зависимость, а не соперничество.** `bootgs` перечисляет `apps-script-utils` среди
своих зависимостей, поэтому в проекте на boot.gs уже есть каждая функция, описанная здесь, — доустанавливать ничего
не нужно. Из этих проверок и собраны его валидация параметров и поиск сервисов.

Что брать:

| Что нужно                                                                        | Что брать                       |
| :------------------------------------------------------------------------------- | :------------------------------ |
| Помощники в уже написанный скрипт — несколько функций, без новой архитектуры     | `apps-script-utils` сам по себе |
| Маршрутизация, контроллеры, внедрение зависимостей, веб-приложение с эндпоинтами | `bootgs`, библиотека уже внутри |

## Agent Skills — научить ИИ-агента этой библиотеке

Если вы пишете на Apps Script вместе с ИИ-агентом, репозиторий [bootgs/skills](https://github.com/bootgs/skills)
публикует для него Agent Skills — упакованные инструкции, которые агент подгружает, когда задача касается
соответствующей темы. Они работают в Claude Code, Gemini CLI, Cursor и во всём, что поддерживает CLI `npx skills`.

Каталог делится надвое:

| Скилл                           | Покрывает                                                                                          |
| :------------------------------ | :------------------------------------------------------------------------------------------------- |
| `apps-script-utils`             | эту библиотеку: соглашение `isX`/`nonX`/`requireX`, проверки, помощники                            |
| `apps-script-triggers`          | простые и устанавливаемые триггеры, форму событий, квоты                                           |
| `apps-script-services`          | безопасную по квотам работу с `SpreadsheetApp`, `PropertiesService`, `CacheService`, `LockService` |
| `apps-script-ui`                | меню, боковые панели, диалоги и подводные камни `google.script.run`                                |
| `apps-script-clasp-workflow`    | CLI `clasp`: push, deploy, версии, несколько окружений                                             |
| `bootgs-quickstart`, `bootgs-*` | фреймворк выше: структуру проекта, архитектуру, валидацию, клиент, OpenAPI                         |

Установка в Claude Code:

```bash
/plugin marketplace add bootgs/skills
/plugin install apps-script@bootgs-skills
```

Установка в любой поддерживаемый агент:

```bash
npx skills add bootgs/skills --skill apps-script-utils
```

После установки агент применяет скилл сам, когда задача касается этой библиотеки, — он перестаёт угадывать имена
функций и начинает пользоваться существующими, соблюдая то соглашение о проверках, которому библиотека
действительно следует.

Впрочем, скилл — это выжимка, а справочник — здесь. Если они расходятся, актуальны страницы этого сайта и код, из
которого они порождены.
