**apps-script-utils** — бібліотека утиліт на TypeScript, створена саме для **Google Apps Script**. Вона збирає в
одному протестованому пакеті те, що в кожному проєкті на GAS однаково доводиться писати руками: роботу з таблицями
та нотацією A1, перевірку типів і значень (`isX`/`nonX`/`requireX`), перетворення рядків і масивів, типізовані
винятки та багато іншого.

## Ключові можливості

- **Зроблено для Google Apps Script** — спроєктовано під середовище виконання GAS та його обмеження, а не
  адаптовано з бібліотеки для Node.js.
- **Широке покриття** — помічники для таблиць, інтерфейсу, мережі та Admin SDK поряд з універсальними утилітами для
  рядків, масивів і об'єктів.
- **TypeScript передусім** — кожна функція має повні описи типів для автодоповнення в IDE та перевірок на етапі
  компіляції.
- **Покрито тестами** — модульні тести на Vitest.
- **Документація з посиланнями** — кожен тип Google Apps Script, що трапляється в API, веде просто в офіційну
  документацію.
- **Єдина обробка помилок** — ієрархія класів винятків замість розрізнених `throw new Error`.

## Де працює бібліотека

Пакет чітко ділиться на дві частини, і цей поділ визначає, звідки функцію можна викликати:

| Частина                                            | Залежить від середовища Apps Script       | Де виконується              |
| :------------------------------------------------- | :---------------------------------------- | :-------------------------- |
| `lang`, `net`, `json`, `html`, `time`, `exception` | Ні                                        | Apps Script, Node.js, тести |
| `appsscript`                                       | Так, для функцій, прив'язаних до сервісів | Лише Apps Script            |

[](apps-script-runtime.md) розбирає, які функції до якої частини належать і що це означає на практиці.

## Структура проєкту

```text
.
├── config/           # Файли конфігурації
├── dist/             # Результат збірки
├── docs/             # Документація: ресурси та джерела цього сайту
├── scripts/          # Службові та допоміжні скрипти
├── src/              # Вихідний код
│   ├── appsscript/   # Утиліти для Google Apps Script
│   ├── exception/    # Класи винятків
│   ├── html/         # Утиліти для HTML
│   ├── json/         # Утиліти для JSON
│   ├── lang/         # Мовні утиліти (масиви, рядки тощо)
│   ├── net/          # Мережа та шляхи
│   ├── time/         # Робота з часом
│   └── index.ts      # Точка входу
├── test/             # Модульні тести
└── vitest.config.ts  # Конфігурація Vitest
```
