# Екосистема

<link-summary>Фреймворк boot.gs, побудований на цій бібліотеці, та Agent Skills, які вчать ШІ-агентів нею користуватися.</link-summary>

<web-summary>Як apps-script-utils пов'язаний із фреймворком boot.gs для Google Apps Script і з Agent Skills, що вчать Claude Code, Gemini CLI та Cursor працювати з обома.</web-summary>

Бібліотека корисна й сама по собі: встановили, імпортували функцію — готово. Водночас вона частина невеликої
екосистеми для розробки на Google Apps Script, і двох сусідів варто знати.

## Boot.gs — фреймворк застосунку

[Boot.gs](https://github.com/bootgs/boot) — фреймворк для структурованих застосунків на Apps Script. Він приносить
контролери, декоратори, впровадження залежностей і шар маршрутизації поверх `doGet` та `doPost` у середовище, яке
саме по собі пропонує глобальні функції й нічого більше.

```bash
npm install bootgs
```

```typescript
import { Get, RestController } from "bootgs";

@RestController("api/sheet")
export class SheetController {
  @Get("active-range")
  getActiveRange(): string {
    return "This action returns the active sheet range.";
  }
}
```

**Відношення до цієї бібліотеки — залежність, а не суперництво.** `bootgs` перелічує `apps-script-utils` серед
своїх залежностей, тому в проєкті на boot.gs уже є кожна функція, описана тут, — доустановлювати нічого не треба. З
цих перевірок і зібрані його валідація параметрів та пошук сервісів.

Що брати:

| Що потрібно                                                                      | Що брати                           |
| :------------------------------------------------------------------------------- | :--------------------------------- |
| Помічники в уже написаний скрипт — кілька функцій, без нової архітектури         | `apps-script-utils` сам по собі    |
| Маршрутизація, контролери, впровадження залежностей, вебзастосунок з ендпоінтами | `bootgs`, бібліотека вже всередині |

## Agent Skills — навчити ШІ-агента цій бібліотеці

Якщо ви пишете на Apps Script разом із ШІ-агентом, репозиторій [bootgs/skills](https://github.com/bootgs/skills)
публікує для нього Agent Skills — запаковані інструкції, які агент підвантажує, коли задача стосується відповідної
теми. Вони працюють у Claude Code, Gemini CLI, Cursor і в усьому, що підтримує CLI `npx skills`.

Каталог ділиться надвоє:

| Скіл                            | Покриває                                                                                         |
| :------------------------------ | :----------------------------------------------------------------------------------------------- |
| `apps-script-utils`             | цю бібліотеку: домовленість `isX`/`nonX`/`requireX`, перевірки, помічники                        |
| `apps-script-triggers`          | прості та встановлювані тригери, форму подій, квоти                                              |
| `apps-script-services`          | безпечну щодо квот роботу з `SpreadsheetApp`, `PropertiesService`, `CacheService`, `LockService` |
| `apps-script-ui`                | меню, бічні панелі, діалоги та підводні камені `google.script.run`                               |
| `apps-script-clasp-workflow`    | CLI `clasp`: push, deploy, версії, кілька середовищ                                              |
| `bootgs-quickstart`, `bootgs-*` | фреймворк вище: структуру проєкту, архітектуру, валідацію, клієнт, OpenAPI                       |

Встановлення в Claude Code:

```bash
/plugin marketplace add bootgs/skills
/plugin install apps-script@bootgs-skills
```

Встановлення в будь-який підтримуваний агент:

```bash
npx skills add bootgs/skills --skill apps-script-utils
```

Після встановлення агент застосовує скіл сам, коли задача стосується цієї бібліотеки, — він перестає вгадувати
імена функцій і починає користуватися наявними, дотримуючись тієї домовленості про перевірки, якої бібліотека
справді дотримується.

Утім, скіл — це витяг, а довідник — тут. Якщо вони розходяться, актуальні сторінки цього сайту й код, з якого їх
породжено.
