# Винятки

<link-summary>Усі класи винятків, які кидає бібліотека.</link-summary>

<web-summary>Довідник класів винятків apps-script-utils: що означає кожен і які функції його кидають.</web-summary>

Типізовані класи винятків, що використовуються в усій бібліотеці. Винятки, прив'язані до сервісів (Таблиці,
Презентації, Admin SDK, мережа), успадковують спільний базовий клас `Exception` — заради однакової обробки помилок.

Позначка **New** означає клас, доданий в останньому випуску; позначка **Deprecated** — клас, який планується
вилучити в одному з майбутніх випусків.
