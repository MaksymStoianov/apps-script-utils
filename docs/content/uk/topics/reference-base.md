# Базові утиліти

<link-summary>Усі функції, що не залежать від середовища виконання: перевірки, масиви, числа, рядки, об'єкти, JSON і HTML.</link-summary>

<web-summary>Довідник усіх незалежних від середовища функцій apps-script-utils: перевірки isX/nonX/requireX, робота з масивами, числами, рядками, об'єктами, JSON, HTML і часом.</web-summary>

Функції, не прив'язані до жодного фреймворку: перевірка типів і значень (`isX`/`nonX`/`requireX`), робота з рядками,
масивами та об'єктами, JSON і HTML. Середовище виконання Google Apps Script їм не потрібне.

Позначка **New** означає функцію, додану в останньому випуску; позначка **Deprecated** — функцію, яку планується
вилучити в одному з майбутніх випусків.
